Book nooks are a fun avenue that Lego is currently exploring with several sets. The idea is that you have a Lego set that you can fit (almost hide) in between your books. In this case, it's a little bookshop (or bookstore) that you can also fold open and display in a different way.

I like books. I like Lego interiors. Having a book nook that's both? Even better.

1690 parts
€130 or $150

![The official box with an image of the bookshop, and it's an 18+ set in the icons-range.](/assets/media/11379_box1_v29_dew7sv4q7r0y.jpg)

## What makes it good?

As stated, I like interiors. This is not a classic Lego building, but it is the interior of one! You get to build tons of bookcases with books, but also some furniture and accessories like chairs, a table, a lamp, a counter that also offers coffee (realistic bookshop!), windows with curtains and some beautiful wrought iron railings along a balcony.

![The book nook partially opened to show all details](/assets/media/_dsc3314.jpg)

![The book nook fully opened ](/assets/media/_dsc3316.jpg)

There are also some hidden details, references and easter eggs. No need to read reviews for that, they're highlighted in the manual!

All these little deviations from just building books also serve another purpose (I assume). According to the manual, it features 112 books in total! The way they're integrated now avoid a tedious and repeating build. You build a bookcase, some books and break it up with some other details. I know some sets I've built that don't this variation in building, and they always make me feel like busy with "model making" except I'm using bricks. The approach of this model is much more practical!

![A bit of the balcony with a seat and two windows](/assets/media/_dsc3319.jpg)

I also found it interesting to see "how we build books these days". Lego has built some experience with books. There are books in 75978 Diagon Alley from 2020, in the modular 10270 Bookshop from 2020, the Gift With Purchase (GWP) 40698 Books Are My Passion from 2024 and many many more. Sometimes there are a few, and (like this set) sometimes there are many. But building techniques have often varied. It's like Lego has been testing: how do we like to build books?

![A front view of a bit of the first floor with books and a desk](/assets/media/_dsc3318.jpg)

## What could be better?

Sadly, it's a bit dark. The bookshop is a narrow space when closed. That kinda works for 10351 Sherlock Holmes: Book Nook as it's more of an alley. But I think this set would do better if it were more open. Especially in a bookcase where it will be surrounded by shelves and books, it can be quite dark in there.

Also, it's quite a fun set to build. But if you're specifically building it because you want to build a nice interior, and actual building might be better value for money.

## Conclusion

The Lego Bookshop Book Nook is a fun build and a pretty display. It looks good, but weirdly, it looks best when not displayed as a book nook!
